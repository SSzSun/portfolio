## Overview

- Retro cassette-futurism design: CRT scanlines, phosphor glow, tape reel animations
- Work experience and projects stored in Supabase
- Admin customizer to add, edit, hide, or delete content right on the page
- Projects shown with tech stack, an architecture diagram, and impact metrics
- Visitor counter, responsive layout, accessible markup

## Quick start

```bash
bun install
cp .env.example .env.local   # add your Supabase URL and publishable key
bun run dev
```

Run the SQL files in `supabase/migrations/` on your Supabase project. `supabase/seed.sql` adds optional sample data.

## Deploy

Import the repo into Vercel, add the variables from `.env.local`, and deploy.
